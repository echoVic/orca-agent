# Side Conversations

A side conversation lets you ask a quick question without adding it to the main
conversation: "what does this function return at the boundary?", "which file
defines the retry policy?". It starts from a copy of the main conversation, only
reads, and disappears when you close it.

## Open, switch, and close

| Action | How |
| --- | --- |
| Open a side conversation | `/side`, or `/side <question>` to ask right away |
| Switch between main and side | `Ctrl+/` |
| Close the side conversation | `Ctrl+C` while it is shown |

Only one side conversation is open at a time, and the main conversation has to
have started first. Switching back to the main conversation keeps the side
conversation open, so `Ctrl+/` returns to it.

When it opens, the side conversation says what it inherited:

~~~text
    ℹ Inherited conversation context.
    ℹ Side conversation opened. Inherited history is reference-only.
 ›  what does token_valid return at the expiry second?
 ●  It returns true: the comparison is `now <= expiry`, so the expiry
    second itself still counts as valid.
────────────────────────────────────────────────────────────────────────────
 ›  Message Orca…  / commands · @ files · $ skills
────────────────────────────────────────────────────────────────────────────
 Side · main running · Ctrl+/ back  deepseek-flash · max · ctx 96% · ? help
~~~

## How it differs from the main conversation

| | Main conversation | Side conversation |
| --- | --- | --- |
| History | Its own | A copy of the main conversation when the side one opened, for reference |
| Approval mode | Your current mode | Plan: it reads and answers, and never edits files or runs commands |
| Recorded | Yes, unless history is disabled | No: closing it discards it |
| Automatic project memory | On for recorded sessions | Off |

Nothing you ask in a side conversation reaches the main one. If an answer
should inform the main task, switch back and say so there.

## The main conversation keeps going

The main conversation keeps running while you are in a side conversation. The
status bar shows what it is doing:

| Status | Meaning |
| --- | --- |
| `main idle` | Waiting for your next message. |
| `main running` | A turn is in progress. |
| `main needs approval` | A tool call waits for your approval. Switch back with `Ctrl+/` to answer it. |
| `main needs input` | Orca asked a question. Switch back to answer it. |
| `main finished` / `main failed` / `main interrupted` | How the last turn ended. |
| `main closed` | The main conversation is no longer available. |

See [Terminal UI](terminal-ui.md) for the rest of the interface.
