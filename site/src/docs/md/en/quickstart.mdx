# Quickstart

Install Orca, provide a DeepSeek API key, check local readiness, and choose an
interactive or headless run.

## Install

```bash
npm install -g @blade-ai/orca
orca --version
```

Native installers are published at [orcaagent.dev](https://orcaagent.dev/):

```bash
curl -fsSL https://orcaagent.dev/install.sh | sh
```

```powershell
irm https://orcaagent.dev/install.ps1 | iex
```

## Configure credentials

Set a credential in the environment. This avoids placing a secret in a project
file and works in CI as well as local shells.

```bash
export ORCA_API_KEY="sk-..."
# DEEPSEEK_API_KEY is also supported.
```

Orca also reads `$ORCA_HOME/auth.json` (or `~/.orca/auth.json`) when it
contains a `DEEPSEEK_API_KEY` entry. Do not commit either form of credential.

## Check local readiness

```bash
orca doctor
```

`doctor` is local and read-only. It checks config syntax, credential presence,
model settings, folder trust, and sandbox readiness. It does not call the
provider, start MCP, create sandbox capabilities, or alter trust/configuration.

```bash
orca doctor --cwd ./my-project --format json
```

The JSON report never contains the API key. Warnings exit successfully; a
failed required check exits with status `1` and includes remediation.

## Start an interactive session

```bash
orca --cwd ./my-project
```

Use `--model`, `--resume`, `--fork`, and `--continue` when needed. In the TUI,
use `/trust` only after reviewing a folder and its intended permissions.

## Run headlessly

```bash
orca exec "Fix the failing test" --verifier "cargo test"
orca exec --output-format jsonl --max-turns 20 "Refactor the parser" > run.jsonl
```

Use `--mode <suggest|auto-edit|full-auto|plan>` to select the tool approval
policy. Explicit resource limits are `--max-turns`, `--max-tool-calls`,
`--max-cost-usd`, and `--max-wall-time-secs`; they are unlimited unless set.

Continue a recorded headless session with:

```bash
orca exec resume SESSION_ID "Continue from the checkpoint"
```

See the [CLI Reference](cli-reference.md) for the exact public command and
option surface, and [Configuration](configuration.md) for configuration
precedence and trust rules.
