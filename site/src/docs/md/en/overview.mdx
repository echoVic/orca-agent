# Orca

Orca is a terminal coding agent for DeepSeek-compatible provider
configurations. The public package is @blade-ai/orca and the canonical
installer is [orcaagent.dev](https://orcaagent.dev/).

## Start here

~~~bash
npm install -g @blade-ai/orca
orca doctor
orca --cwd ./my-project
~~~

The interactive command opens the TUI. It is the best surface for reviewing
approvals, live activity, local history, and workflow state.

For automation, use the small public command surface:

| Command | Use |
| --- | --- |
| orca doctor | Read-only local diagnostic report. |
| orca exec | One non-interactive task with optional limits, verifier, and JSONL output. |
| orca workflow | Launch and control persisted workflow programs. |
| orca trust | Inspect or change the folder-trust decision. |

~~~bash
orca exec --mode suggest --verifier "cargo test" "Fix the failing test"
orca exec --output-format jsonl "Inspect the project" > run.jsonl
orca workflow list --status running
orca trust show --cwd ./my-project
~~~

## Safety model

The model proposes actions; the runtime evaluates the effective approval,
permission, folder-trust, and sandbox policy before an action executes. A
successful model response is therefore not completion proof. Prefer a verifier
for code-changing work, preserve terminal tool events, and inspect an
interrupted action before attempting it again.
