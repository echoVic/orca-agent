# Mention Search

Type `@` in the input to attach something to your message: a file from the
workspace, a skill, a plugin, or an MCP resource. The picker searches as you
type. `$` inserts a skill directly.

## The picker

~~~text
 › fix the expiry check in @tok
╭ Mentions ──────────────────────────────────────────────────────────────╮
│ › file    src/auth/token.rs  ~/projects/api                            │
│   file    src/auth/          ~/projects/api                            │
│   skill   code-review  code-review — Review a diff for bugs and risk   │
│   plugin  github  github — Issues, pull requests, and checks           │
╰────────────────────────────────────────────────────────────────────────╯
~~~

Each row shows what kind of item it is, its name, and a detail: the workspace
folder for files, the description for skills and plugins.

| Key | Action |
| --- | --- |
| Type | Filter the list. |
| `↑` / `↓` | Move the selection. |
| `PgUp` / `PgDn` | Move a page. |
| `Home` / `End` | Jump to the first or last item. |
| `Tab` / `Enter` | Pick the item. Picking a directory opens it so you can keep browsing. |
| `Esc` | Close the picker. |

## What a mention attaches

The mention stays in your message as written, for example `@src/auth/token.rs`,
and Orca remembers exactly which item you picked. When you send the message,
each mention adds its content after your text:

| Mention | What the model receives |
| --- | --- |
| File | The file's contents. A directory cannot be attached. |
| Skill | The skill's instructions. |
| Plugin | The plugin's manifest. |
| MCP resource | The resource, as read from its MCP server. |

A file mention resolves to the file you picked inside the workspace. If the
item is no longer available when you send, for example a skill that was
removed, Orca reports it instead of sending the message.

## Skills with `$`

`$` opens the same picker limited to skills, which is the quickest way to run a
skill on one message. Skills come from `~/.orca/skills` (or
`$ORCA_HOME/skills`), `~/.agents/skills`, and, once the folder is trusted, the
project's `.orca/skills` and `.agents/skills`. See
[Skills & plugins](skills-plugins.md).
