# Skills

A skill is a directory containing a SKILL.md instruction file. Orca discovers
skills from:

1. $ORCA_HOME/skills, or ~/.orca/skills when ORCA_HOME is unset;
2. ~/.agents/skills;
3. .orca/skills inside a trusted project; and
4. .agents/skills inside a trusted project.

Project skills are ignored until the workspace is trusted. This prevents a
newly opened repository from silently injecting instructions.

## Minimal skill

~~~markdown
---
name: Rust review
description: Review Rust changes for correctness and recovery risks
when_to_use: Use for changes to runtime ownership or persistence
paths:
  - "crates/**/*.rs"
---

Read the owning runtime path before commenting.
Prioritize concrete failure modes and missing tests.
~~~

The directory name is the skill ID and may contain ASCII letters, digits,
hyphens, or underscores. The supported metadata fields are name, description,
when_to_use, and paths.

## Invoke a skill

Mention a discovered skill by ID in the prompt:

~~~text
$rust-review Review the current branch.
$rust-review:permissions Review the permission changes.
~~~

The optional text after the colon is substituted for {{arg}} in the skill
body. In the TUI, discovered skills are also available through mention search.

There is no public command for loading or unloading a skill. Add, edit, or
remove its SKILL.md file, then start the task that mentions it.
