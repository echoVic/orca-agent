# Context and Compaction

The context window is managed by the runtime during a turn. There is no
separate public command for inspecting or mutating it. Use the interactive TUI
for live context information, or consume the execution event stream in an
automated environment.

~~~bash
orca exec --output-format jsonl "Inspect the current implementation" |
  jq -c 'select(.type == "context.updated" or .type == "context.compacted")'
~~~

context.updated carries the observed token usage and limit for that point in a
run. context.compaction.started and context.compacted identify a runtime
compaction boundary. Treat those events as observations: they explain why an
older detail may no longer be in the immediate prompt, not a license to discard
durable conversation or tool records.

For a task that needs a precise earlier fact, include the file path, test name,
or session boundary in the next prompt rather than relying on an implicit
context guess.
