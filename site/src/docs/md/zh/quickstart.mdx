# 快速上手

安装 Orca，配置 DeepSeek API 密钥，检查本地就绪状态，然后选择交互式或无界面运行。

## 安装

```bash
npm install -g @blade-ai/orca
orca --version
```

原生安装器发布在 [orcaagent.dev](https://orcaagent.dev/)：

```bash
curl -fsSL https://orcaagent.dev/install.sh | sh
```

```powershell
irm https://orcaagent.dev/install.ps1 | iex
```

## 配置凭据

建议通过环境变量配置凭据。这样不会把密钥写入项目文件，也适用于 CI。

```bash
export ORCA_API_KEY="sk-..."
# 同样支持 DEEPSEEK_API_KEY。
```

当 `$ORCA_HOME/auth.json`（或 `~/.orca/auth.json`）包含
`DEEPSEEK_API_KEY` 时，Orca 也会读取该文件。不要把任一种凭据提交到源码库。

## 检查本地就绪状态

```bash
orca doctor
```

`doctor` 是本地只读检查。它检查配置语法、凭据是否存在、模型设置、目录信任和沙箱
就绪状态；不会调用模型服务、启动 MCP、创建沙箱 capability，也不会改变信任或配置。

```bash
orca doctor --cwd ./my-project --format json
```

JSON 报告不会包含 API 密钥。只有警告时正常退出；必要检查失败时以状态码 `1` 退出，
并附上修复建议。

## 启动交互式会话

```bash
orca --cwd ./my-project
```

需要时使用 `--model`、`--resume`、`--fork` 和 `--continue`。在 TUI 中，只有检查过
目录内容和预期权限后才使用 `/trust`。

## 无界面运行

```bash
orca exec "修复失败的测试" --verifier "cargo test"
orca exec --output-format jsonl --max-turns 20 "重构解析器" > run.jsonl
```

用 `--mode <suggest|auto-edit|full-auto|plan>` 选择工具审批策略。显式资源限制是
`--max-turns`、`--max-tool-calls`、`--max-cost-usd` 和 `--max-wall-time-secs`；
未设置时没有隐式上限。

恢复已记录的无界面会话：

```bash
orca exec resume SESSION_ID "从检查点继续"
```

准确的公开命令和选项请见 [CLI 参考](cli-reference.md)，配置优先级和信任规则请见
[配置说明](configuration.md)。
