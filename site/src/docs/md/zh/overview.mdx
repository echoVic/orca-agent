# Orca

Orca 是面向 DeepSeek 兼容提供商配置的终端编码 Agent。公开包名是 @blade-ai/orca，规范安装入口是 [orcaagent.dev](https://orcaagent.dev/)。

## 从这里开始

~~~bash
npm install -g @blade-ai/orca
orca doctor
orca --cwd ./my-project
~~~

交互命令会打开 TUI。审批、实时活动、本地历史和工作流状态都应在这里查看。

自动化使用这一组小而明确的公开命令：

| 命令 | 用途 |
| --- | --- |
| orca doctor | 只读本地诊断报告。 |
| orca exec | 执行一个非交互任务，可附加限制、验证器和 JSONL 输出。 |
| orca workflow | 启动和控制持久化工作流程序。 |
| orca trust | 查看或修改目录信任决定。 |

~~~bash
orca exec --mode suggest --verifier "cargo test" "修复失败的测试"
orca exec --output-format jsonl "检查项目" > run.jsonl
orca workflow list --status running
orca trust show --cwd ./my-project
~~~

## 安全模型

模型提出操作；真正执行前，运行时会评估生效的审批、权限、目录信任和沙箱策略。因此模型的文字回复不等于完成证明。代码改动优先使用验证器，保存工具终态事件；中断的操作在再次尝试前先检查目标状态。
