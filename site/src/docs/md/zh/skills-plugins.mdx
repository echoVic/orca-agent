# Skills

一个 skill 是包含 SKILL.md 指令文件的目录。Orca 从以下位置发现 skills：

1. 设置 ORCA_HOME 时读取 $ORCA_HOME/skills，否则读取 ~/.orca/skills；
2. ~/.agents/skills；
3. 已受信任项目中的 .orca/skills；
4. 已受信任项目中的 .agents/skills。

项目 skill 在工作区受信任前不会加载，避免刚打开的仓库静默注入指令。

## 最小 skill

~~~markdown
---
name: Rust review
description: 检查 Rust 改动的正确性和恢复风险
when_to_use: 修改运行时所有权或持久化逻辑时使用
paths:
  - "crates/**/*.rs"
---

评论前先阅读真正拥有状态的运行时路径。
优先报告具体失败模式和缺失测试。
~~~

目录名就是 skill ID，只能包含 ASCII 字母、数字、连字符或下划线。支持的元数据字段是 name、description、when_to_use 和 paths。

## 调用 skill

在提示词中按 ID 引用已发现的 skill：

~~~text
$rust-review 审查当前分支。
$rust-review:permissions 审查权限改动。
~~~

冒号后的可选文本会替换 skill 正文中的 {{arg}}。TUI 的 mention 搜索也会展示已发现的 skills。

公开 CLI 没有加载或卸载 skill 的命令。新增、编辑或删除 SKILL.md 后，启动引用它的任务即可。
