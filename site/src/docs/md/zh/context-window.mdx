# 上下文与压缩

上下文窗口由运行时在一次回合中管理，没有单独的公开命令用于检查或修改它。实时信息请看交互式 TUI；自动化场景则消费执行事件流。

~~~bash
orca exec --output-format jsonl "检查当前实现" |
  jq -c 'select(.type == "context.updated" or .type == "context.compacted")'
~~~

context.updated 给出该时刻观察到的 token 用量与上限。context.compaction.started 和 context.compacted 标记运行时压缩边界。这些事件只是观察结果：它们解释某些较早细节为什么不在当前提示中，并不允许丢弃持久化的对话或工具记录。

需要引用先前精确事实时，在下一条提示中提供文件路径、测试名或会话边界，而不是依赖隐式的上下文猜测。
