# 会话命令


Orca 通过 TUI 输入中的 `/` 前缀提供丰富的会话管理命令。本页涵盖所有会话命令、会话选择器和会话存储。

## 会话管理命令

### 完整命令表

| 命令 | 描述 | 示例 |
|------|------|------|
| `/new` | 开始新会话 | `/new` |
| `/resume <id>` | 恢复现有会话 | `/resume 42` |
| `/fork <spec>` | 从会话检查点分叉 | `/fork 42:turn-17` |
| `/rename <name>` | 重命名当前会话 | `/rename 修复认证 bug` |
| `/status` | 显示会话状态和预算 | `/status` |
| `/copy` | 复制最后一条智能体消息 | `/copy` |
| `/export` | 将会话导出为 JSON | `/export` |
| `/delete <id>` | 永久删除会话 | `/delete 42` |
| `/sessions` | 在选择器中列出所有会话 | `/sessions` |

### `/new` — 开始新会话

```
/new
```

创建新会话，包含：
- 新的上下文窗口（1M tokens 可用）
- 相同的项目上下文（文件树、git 状态）
- 应用的默认配置（模型、审批等）
- 旧会话被保留并可恢复

适用场景：
- 完成一项任务并开始另一项
- 上下文窗口即将满
- 你想重置对话历史

### `/resume` — 恢复现有会话

```
/resume <session-id>
```

恢复之前的会话，恢复以下内容：
- 完整对话历史
- 所有工具结果和文件变更
- 预算状态（剩余回合和费用）
- 光标位置和视图状态

```bash
# 恢复会话 42
/resume 42

# 恢复最近的会话
/resume last
```

### `/fork` — 从检查点分叉

```
/fork <session-id>:<turn-id>
```

创建从另一个会话特定点分支的新会话：

```
# 从会话 42 的第 17 回合分叉
/fork 42:turn-17

# 从会话 42 的开头分叉
/fork 42:turn-1

# 带自定义名称分叉
/fork 42:turn-17 修复替代方案
```

分叉适用于：
- 想在不丢失原始方案的情况下尝试替代方法
- 会话走入死胡同，想回溯
- 想并排比较两个解决方案

### `/rename` — 重命名会话

```
/rename 修复登录 token 过期 bug
```

设置会话的人类可读名称。名称在会话选择器和 `sessions list` 中显示。

## 模式命令

Orca 还提供模式切换命令：

| 命令 | 描述 |
|------|------|
| `/plan` | 切换到 `plan` 审批模式 |
| `/suggest` | 切换到 `suggest` 审批模式 |
| `/auto-edit` | 切换到 `auto-edit` 审批模式 |
| `/full-auto` | 切换到 `full-auto` 审批模式 |
| `/reasoning low` | 将推理努力设置为低 |
| `/reasoning medium` | 将推理努力设置为中等 |
| `/reasoning high` | 将推理努力设置为高 |
| `/model <name>` | 切换到不同的模型 |
| `/verbose` | 切换调试日志 |

## 会话存储

### 存储位置

Orca将会话存储为 SQLite 数据库：

| 平台 | 路径 |
|------|------|
| macOS | `~/Library/Application Support/orca/sessions/` |
| Linux | `~/.local/share/orca/sessions/` |
| Windows | `%APPDATA%/orca/sessions/` |

### 手动会话管理

```bash
# 列出所有会话
orca sessions list

# 显示会话详情
orca sessions show 42

# 将会话导出为 JSON
orca sessions export 42 > session-42.json

# 删除会话
orca sessions delete 42

# 清除所有超过 30 天的已完成会话
orca sessions purge --older-than 30d
```

### 会话备份

会话以独立的 `.db` 文件存储。备份方法：

```bash
# 复制会话目录
cp -r ~/.local/share/orca/sessions/ /backup/orca-sessions/

# 或使用 Orca 的导出命令进行结构化备份
orca sessions export --all > all-sessions.json
```

> **提示：** 会话数据库是可移植的。你可以在机器之间复制它们，或将其包含在版本控制中以进行团队协作。
