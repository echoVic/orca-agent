# 会话续传

Orca 将已记录的对话保存在本地，以便交互式或无头任务从持久化边界继续。公开命令行在启动时提供续传能力，而非另一套会话管理命令。

## 交互式启动

~~~bash
orca --resume SESSION_ID
orca --fork SESSION_ID
orca --continue
~~~

--resume 不带选择器时会打开交互式选择器。使用选择器浏览已记录的对话，再选择恢复或分叉。

## 无头启动

~~~bash
orca exec --resume SESSION_ID "继续排查"
orca exec --fork SESSION_ID "尝试第二种实现"
orca exec --continue "继续处理验证失败"
orca exec resume SESSION_ID "从检查点继续"
~~~

仅在恢复或继续时使用 --resume-at MESSAGE_ID，表示恢复到某个已持久化消息为止。互斥规则见[恢复无头运行](orca-exec-resume.md)。

## 哪些状态是持久化的

已记录对话包含恢复所需的模型和工具历史，但这不等于每个进行中的外部副作用都已完成。崩溃或中断后，若工具已经启动却没有终态结果，应在再次写入、发请求或运行命令前先检查状态。

交互式选择器是浏览本地历史的支持入口。自动化场景应把选出的会话 ID 与任务元数据一起保存，并通过上述命令重新传入。
