# 恢复无头运行

当已记录的无头运行需要继续时，使用 orca exec resume。选择器可以是会话 ID、无歧义前缀或 latest。

~~~bash
orca exec resume SESSION_ID "从上一个检查点继续"
orca exec resume latest --max-turns 10 --max-cost-usd 2 "运行聚焦测试"
~~~

补充说明是位置参数，不是命名参数。恢复子命令支持全部执行参数，包括 --verifier、--output-format 和资源限制。

## 其他续传方式

新建一次 orca exec 调用时也能表达同样的选择：

| 目的 | 公开形式 |
| --- | --- |
| 恢复指定会话 | orca exec --resume SESSION_ID "继续" |
| 恢复到已持久化消息边界 | orca exec --resume SESSION_ID --resume-at MESSAGE_ID "继续" |
| 继续最近会话 | orca exec --continue "继续" |
| 从会话分叉 | orca exec --fork SESSION_ID "尝试另一种实现" |

--resume、--fork 和 --continue 互斥。--resume-at 需要与恢复或继续一起使用，且不能与分叉同时使用。续传操作必须记录历史，因此不能与 --no-history 一起使用。

## 选择正确的边界

恢复会继续原始会话；分叉会从选定会话创建一条新的已记录分支，适合不想改变原有历史的替代方案。两者只恢复已持久化状态。若工具调用在终态记录前中断，应先当作可能已生效并检查结果，不能直接重复。

公开 CLI 不提供批量列出、导出或删除本地会话的命令。需要浏览本地历史时，打开交互式 TUI，再将选中的 ID 放入无头命令。
