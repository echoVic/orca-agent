# Mention 搜索

在输入框里输入 `@`，可以给消息附上内容：工作区里的文件、skill、插件或 MCP 资源。选择器会随着输入实时搜索。`$` 用来直接插入 skill。

## 选择器

~~~text
 › fix the expiry check in @tok
╭ Mentions ──────────────────────────────────────────────────────────────╮
│ › file    src/auth/token.rs  ~/projects/api                            │
│   file    src/auth/          ~/projects/api                            │
│   skill   code-review  code-review — Review a diff for bugs and risk   │
│   plugin  github  github — Issues, pull requests, and checks           │
╰────────────────────────────────────────────────────────────────────────╯
~~~

每一行依次显示条目类型、名称和补充信息：文件显示所在的工作区目录，skill 和插件显示简介。

| 按键 | 作用 |
| --- | --- |
| 输入文字 | 筛选列表。 |
| `↑` / `↓` | 移动选中项。 |
| `PgUp` / `PgDn` | 翻一页。 |
| `Home` / `End` | 跳到第一项或最后一项。 |
| `Tab` / `Enter` | 选中该项。选中目录会进入这个目录，可以继续往下找。 |
| `Esc` | 关闭选择器。 |

## Mention 附上的内容

Mention 会按原样留在你的消息里，比如 `@src/auth/token.rs`，Orca 会记住你选中的具体是哪一项。发送消息时，每个 mention 会把对应内容附在你的文字后面：

| Mention | 模型收到的内容 |
| --- | --- |
| 文件 | 文件内容。目录不能作为附件。 |
| Skill | 这个 skill 的指令。 |
| 插件 | 插件的 manifest。 |
| MCP 资源 | 从对应 MCP 服务器读取的资源内容。 |

文件 mention 对应的是你在工作区里选中的那个文件。发送时如果某一项已经不可用（比如 skill 被删掉了），Orca 会报错，而不是照常发出消息。

## 用 `$` 插入 skill

`$` 会打开同一个选择器，但只列出 skill，这是对单条消息使用某个 skill 最快的方式。Skills 来自 `~/.orca/skills`（或 `$ORCA_HOME/skills`）、`~/.agents/skills`，以及目录受信任后项目里的 `.orca/skills` 和 `.agents/skills`。详见[Skills 与插件](skills-plugins.md)。
