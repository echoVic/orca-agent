# 侧边对话

侧边对话用来问一些不想加进主对话的小问题，比如"这个函数在边界值时返回什么？""重试策略是在哪个文件里定义的？"。它从主对话的一份副本开始，只读不改，关闭后就消失。

## 打开、切换与关闭

| 操作 | 方式 |
| --- | --- |
| 打开侧边对话 | `/side`，或用 `/side <问题>` 直接提问 |
| 在主对话和侧边对话之间切换 | `Ctrl+/` |
| 关闭侧边对话 | 在侧边对话里按 `Ctrl+C` |

同一时间只能打开一个侧边对话，而且要先开始主对话。切回主对话时侧边对话不会关闭，再按 `Ctrl+/` 就能回去。

侧边对话打开时，会说明它继承了什么：

~~~text
    ℹ Inherited conversation context.
    ℹ Side conversation opened. Inherited history is reference-only.
 ›  what does token_valid return at the expiry second?
 ●  It returns true: the comparison is `now <= expiry`, so the expiry
    second itself still counts as valid.
────────────────────────────────────────────────────────────────────────────
 ›  Message Orca…  / commands · @ files · $ skills
────────────────────────────────────────────────────────────────────────────
 Side · main running · Ctrl+/ back  deepseek-flash · max · ctx 96% · ? help
~~~

## 和主对话的区别

| | 主对话 | 侧边对话 |
| --- | --- | --- |
| 历史 | 自己的历史 | 打开时主对话的一份副本，仅供参考 |
| 审批模式 | 你当前的模式 | Plan：只读取和回答，不会改文件或执行命令 |
| 是否记录 | 记录（除非关闭了历史） | 不记录：关闭即丢弃 |
| 自动项目记忆 | 记录的会话默认开启 | 关闭 |

在侧边对话里问的内容不会进入主对话。如果某个回答对主任务有用，切回主对话再说一遍。

## 主对话照常进行

你在侧边对话里时，主对话会继续运行。状态栏会显示它的状态：

| 状态 | 含义 |
| --- | --- |
| `main idle` | 在等你的下一条消息。 |
| `main running` | 有轮次正在运行。 |
| `main needs approval` | 有工具调用在等你批准。按 `Ctrl+/` 切回去处理。 |
| `main needs input` | Orca 问了一个问题。切回去回答。 |
| `main finished` / `main failed` / `main interrupted` | 上一轮的结束方式。 |
| `main closed` | 主对话已不可用。 |

界面其余部分见[终端界面](terminal-ui.md)。
