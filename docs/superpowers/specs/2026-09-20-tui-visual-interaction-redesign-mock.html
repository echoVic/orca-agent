把 spec 里的方案一和方案二画出来。每个场景按 100 列 × 34 行的终端网格排版，终端内颜色取自 theme.rs 的 Dark 调色板（品牌蓝 #4D6BFE）。关键场景可以切换「改前 / 改后」，改前画面来自今晚实际抓取的终端截图。

点一下终端画面获得键盘焦点，然后按场景提示里的键 终端里带下划线悬停效果的行可以点击 改前 = 当前实现 · 改后 = 方案效果

画面里的会话内容来自真实历史会话（ego-browser 那段）和 spec 里的示例；工具耗时、token、成本等数字是示意值。鲸鱼字符画取自当前工作树里的实现。
