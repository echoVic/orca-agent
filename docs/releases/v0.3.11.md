# Orca v0.3.11

Orca v0.3.11 closes the reliability loop across headless runs, terminal
interaction, MCP elicitation, server permissions, and automatic project memory.

## What Changed

- Headless max-turn runs now preserve the actual terminal trajectory. Streamed
  terminal projections are checked against persisted tool records so a run
  cannot report a clean completion while its durable transcript says otherwise.
- Terminal waiters observe cancellation, stop their owned work, and join before
  returning. This keeps TUI cancellation and terminal cleanup on one lifecycle
  owner without detached waiters.
- MCP SSE tool calls now route elicitation through the runtime handler, validate
  request and terminal response IDs, bound response bodies, and cancel an
  in-flight elicitation response POST. Decline, malformed requests, wire-level
  exchanges, and cancellation are covered by transport contracts.
- Network permissions inherited from a thread profile now ask for an allowlist
  grant once, persist the grant, and retry the original command. Explicit
  denylist entries still fail closed without prompting.
- JSONL server tool approvals remain attached to the runtime-owned interaction
  rail, including strict auto-review follow-up approvals. Automatic project
  memory appends use a cross-process lock and staged writes so cancellation
  cannot leave an empty or partial memory file.
- Contract fixtures use deterministic local servers and blocking-mode
  transitions, removing external DNS and nonblocking-socket races from the
  reliability suite.

## Compatibility

CLI arguments, TUI workflows, server/JSONL and ACP protocols, SQLite schemas,
and persisted transcript formats are unchanged. Existing regular transcripts
and memory files remain readable. The release changes lifecycle behavior only:
cancelled work is joined before return, inherited allowlist misses can request a
grant, and automatic memory writes are skipped when cancellation wins.

## Upgrade

```bash
npm install -g @blade-ai/orca@0.3.11
```

macOS and Linux native installer:

```bash
curl -fsSL https://orcaagent.dev/install.sh | \
  INSTALL_DIR=/usr/local/bin ORCA_VERSION=0.3.11 sh
```

Windows PowerShell, including workspace sandbox setup:

```powershell
& ([scriptblock]::Create((irm https://orcaagent.dev/install.ps1))) -Version 0.3.11 -SetupSandbox
```
