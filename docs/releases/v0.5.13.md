# Orca v0.5.13

Changes since v0.5.12:
- Cost estimates follow DeepSeek's current prices and weekday peak hours,
  with background price refresh, fixed user prices and pricing diagnostics.
  Estimates can be higher, so cost budgets can stop a run sooner.
- Fixed request prefixes are about 24% smaller after removing duplicate tool
  descriptions and hiding tools that cannot run. The measured first request
  fell from 10,517 to 8,094 prompt tokens.
- Computer use preserves selections in focused elements, rechecks focus
  before input, and can safely send ordinary text keys to canvases that
  report no focus. UU overlay handling verifies the process signature and
  window stack; active UU sessions remain untested.
- Exec JSONL batches consecutive text deltas, and exec and server requested
  tool events include canonical action and target metadata.
- Invalid project configuration preserves user settings. The README adds
  badges and a first-run terminal demo, and macOS live tests run on stable Rust
  with stronger fixture cleanup.

## Changes

### Pricing and cost estimates

The built-in prices were checked against
[DeepSeek's official pricing page](https://api-docs.deepseek.com/quick_start/pricing)
on 2026-10-20. Prices are in USD per million tokens:

| Model | Period | Cache hit | Cache miss | Output |
| --- | --- | ---: | ---: | ---: |
| deepseek-flash | Off-peak | 0.003 | 0.15 | 0.6 |
| deepseek-flash | Peak | 0.006 | 0.30 | 1.2 |
| deepseek-v4-pro | Off-peak | 0.022 | 0.66 | 1.98 |
| deepseek-v4-pro | Peak | 0.044 | 1.32 | 3.96 |

Peak hours are Monday to Friday, 09:00–12:00 and 14:00–18:00 Beijing time
(UTC 01:00–04:00 and 06:00–10:00), excluding Chinese public holidays.
Weekends and the listed weekday holidays are off-peak all day. This release
keeps the published 2026 holiday table; the State Council has not yet
published the 2027 schedule, so no 2027 dates are added.

Orca stores a version-2 price cache at `$ORCA_HOME/pricing-cache.json`.
At session startup, each process can start one background refresh from
`https://models.dev/api.json` when the cache is missing, at least a day old,
or belongs to another source. A failed refresh keeps the existing prices
and does not block the turn.

Fetch time controls refresh freshness; each model's content-update date
controls price precedence. Cached content dated on or after the built-in
check date can replace a known model's built-in prices. Older content only
adds models absent from the built-in table. Fetching unchanged old content
again does not make it override newer built-in prices. Invalid cache entries
and implausible prices are ignored.

`CostTracker` prices each usage update at the current time. Fixed prices from
the user configuration reach all cost trackers and do not receive the peak
multiplier. `orca doctor` reports the effective price source, refresh switch,
and current peak or off-peak period.

### Computer use

Element-targeted `type` preserves the selection and insertion point when the
target already has focus: selected text is replaced, or text is inserted at
the existing caret. An unfocused target is focused and receives text at the
end. The model-facing `computer` tool's `text` description explains this
behavior.

When an app omits `AXFocusedUIElement` but the target itself reports
`AXFocused = true`, Orca recognizes that focus, preserving the selection and
avoiding an extra foreground Type or Key click. Background typing rechecks
the actual keyboard recipient before skipping focus. If focus has moved,
Orca refocuses the target and collapses the selection to the end so Cocoa's
select-all-on-refocus behavior does not replace the whole field.

Foreground element typing preserves the selection only when the target was
originally focused and is still focused at the click decision. If no click
decision ran, Orca checks focus again before deciding whether to collapse.

An ordinary text key without an element target can reach a canvas-style app
only after the focus wait expires, both application and system focus are
absent, and a strict scan of the window confirms there are no password
fields. An uncertain or incomplete scan refuses the action. The result note
states that the app reports no focused element.

Foreground clicks can look through UU Remote's full-screen overlay only
after validating the process's signing identifier and Team ID, and only when
the first window at the click point beneath authenticated overlays belongs
to the target app. Other covering windows, including fully transparent ones,
still block the click. This path has not been tested in an active UU session.

The macOS live suite now uses `libtest-mimic` on stable Rust, retaining the
AppKit main run loop, a fresh named thread for each test, and suite-level
foreground and pointer restoration. New regressions cover focused selections,
missing application-level focus and foreground actions that must not click.
Safari helpers identify their own page by `AXURL`; TextEdit expectations
follow caret placement and accept both safe Save panel hit-test outcomes.
The deadline fixture leaves more headroom, and native helpers retry transient
stale-handle and `CannotComplete` reads.

Fixture cleanup collects every PID receipt from its private logs and confirms
process exit after termination requests, escalating when needed. It leaves
other sessions' processes alone and reports surviving processes as cleanup
failures. The reviewed macOS-only operations are registered in the platform
boundary inventory.

### Runtime, exec and server

The system prompt no longer repeats the tool descriptions already sent in
the tool schema, and unavailable tools are omitted:
- workflow IPC tools are exposed only inside workflow child processes;
- MCP resource tools are omitted when no MCP server is enabled;
- headless `orca exec` omits `ask_user_question`;
- outside a Git work tree, `git_status` is omitted and the prompt says
  `Git repository: no`.

Git work-tree markers are validated, and hidden computer tools no longer
trigger unused host capability probes. Fixed request prefixes are about 24%
smaller; in the measured run, the first request used 8,094 prompt tokens
instead of 10,517.

`orca exec --output-format jsonl` coalesces consecutive reasoning or message
deltas for the same item, using flush thresholds of about one second or
64 KiB. Concatenated text is unchanged, but retained event envelopes mean
`seq` values may skip.

In both exec JSONL and server mode, `tool.call.requested` carries action and
target metadata derived from the tool registry, including for MCP and
external tools. Shell-task attachment also uses the canonical tool action.

Invalid project configuration now falls back to the user configuration
instead of discarding it and using defaults.

### Documentation

The README adds project badges and a terminal demonstration of the first
run. Model and configuration guides explain dynamic pricing, peak hours,
fixed prices and the refresh switch; the JSONL guide describes coalesced
events. The release checklist now requires checking built-in prices and
advancing their verification date.

## Compatibility

- **Higher cost estimates.** The bundled rates now match DeepSeek's official
  prices; output prices more than doubled from the old estimates, and
  weekday peak hours in Beijing double the rate again. A `max_cost_usd`
  budget can therefore stop a run sooner.
- **Background network access.** Refresh is enabled by default and may
  access `https://models.dev/api.json` when cached prices are missing or
  at least 24 hours old. Put `[pricing] refresh = false` in user configuration
  to disable it. Development builds, including debug builds and executables
  under a Cargo `target` directory, skip refresh unless `ORCA_PRICING_URL`
  is set; `refresh = false` still disables it.
- **User-only pricing configuration.** `[models."<name>".pricing]` sets
  fixed prices for all hours, and `[pricing] refresh` controls refresh.
  Both settings are stripped from project configuration because they affect
  cost-budget enforcement. Invalid project configuration now preserves
  valid user settings.

  ```toml
  [pricing]
  refresh = false

  [models."my-model".pricing]
  input_cache_hit = 0.05
  input_cache_miss = 0.5
  output = 1.5
  ```

  All three prices are required, in USD per million tokens.
- **Element-targeted typing.** An already-focused target keeps its selection
  and caret instead of always appending. To append, move the caret to the end
  first. Targets that need refocusing still receive text at the end.
- **Tool availability.** Workflow IPC, MCP resources, `ask_user_question` and
  `git_status` are no longer advertised in contexts where they cannot run,
  as described above.
- **JSONL consumers.** Consecutive text deltas can be merged without changing
  their combined text; do not require contiguous `seq` values.
  `tool.call.requested` adds registry-derived action and target fields in
  exec JSONL and server mode.
- **UU Remote.** Overlay recognition and signature checks are implemented,
  but the active-session path remains untested.
- **Platforms and approvals.** Computer use remains limited to macOS 14 or
  later in the interactive TUI's main session. App and password approvals
  retain their existing rules.
