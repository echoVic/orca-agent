# Orca v0.3.22

Orca v0.3.22 makes interactive TUI controls explicit and restores terminal-native editing behavior in the composer.

## Interactive session configuration

- Replace the read-only `/config show` TUI command with `/config`.
- Open an owned configuration panel for the current session instead of printing a transcript block.
- Edit the active model, reasoning effort, and approval mode with arrow keys.
- Apply the complete settings patch with Enter, or close without changes with Esc.
- Keep configuration input isolated from transcript search and other global shortcuts while the panel is open.

The standalone `orca config` CLI commands remain unchanged.

## Structured user questions

- Present `ask_user_question` choices in a dedicated selection dialog instead of requiring a free-form composer response.
- Show labels and descriptions, support numbered selection, and preserve optional previews.
- Support multi-select questions with Space and submit the checked labels with Enter.
- Allow typing to switch to a custom answer without losing the pending runtime interaction.
- Restore the dialog and original draft if interaction submission fails.

## Terminal-native composer editing

- Separate Editor shortcuts from Global, Idle, Running, and Approval contexts.
- Preserve readline-style movement and deletion keys while a draft is present:
  - `Ctrl+A` / `Ctrl+E`: line start / end
  - `Ctrl+B` / `Ctrl+F`: one character left / right
  - `Alt+B` / `Alt+F`: one word left / right
  - `Ctrl+P` / `Ctrl+N`: editor up / down
  - `Ctrl+W`: delete the previous word
  - `Ctrl+D`: delete forward
  - `Ctrl+K`: delete to line end
  - `Ctrl+U`: clear the composer
- Keep the previous application actions as empty-composer fallbacks: transcript search, shortcut help, history navigation, half-page scrolling, and backgrounding the current turn.
- Let multiline drafts own Up and Down before running-view transcript scrolling.
- Route Esc through Vim first. Insert mode exits to Normal, and Vim command state is no longer intercepted by backtrack or interrupt handling.
- Only allow idle backtracking when the composer is empty. `Ctrl+C` remains the process-level cancel and quit control.

## Validation

- Add a cross-context collision matrix covering the editor/global, editor/idle, and editor/running overlaps.
- Add regression tests for readline editing, `Ctrl+U`, draft-aware `Ctrl+F`, running `Ctrl+B`, and Vim Esc ownership.
- Keep shortcut help synchronized with the active Editor context and empty-composer fallback behavior.

## Install

```bash
npm install -g @blade-ai/orca@0.3.22
```

Or download the platform archive from the GitHub Release and verify the included SHA-256 checksum.
