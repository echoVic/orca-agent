# Orca v0.4.17

Review-hardened Goal recovery.

## Changes

- Goal recovery reuses the canonical generation-stop terminal mapping.
- `NotStartedReason` terminal semantics are covered by a focused regression.
- Release verification documents executable recovery, formatting, and compile
  commands.

## Compatibility

No persisted format or public protocol changes. Existing sessions retain the
same durable recovery behavior.

## Verification

```bash
cargo test -p orca-runtime --lib generation_stop_terminal_mapping_preserves_not_started_reasons --locked -- --test-threads=1
cargo test -p orca-runtime --lib surface_goal_terminal_checkpoint_failure_recovers_exact_verified_batch --locked -- --test-threads=1
cargo fmt --all -- --check
cargo check -p orca-runtime --lib --offline
```

## Upgrade

```bash
npm install -g @blade-ai/orca@0.4.17
```
