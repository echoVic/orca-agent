# Orca v0.4.14

Deterministic child activity contracts.

This patch republishes the live child conversation fixes with the final
contract updates found while running the full workspace gate.

## Changes

- Fenced TUI async children use durable task ownership and remain visible in
  `/tasks` and Conversation.
- Legacy hosted agents without a parent fence retain their controller route.
- Root session helpers distinguish persisted child sessions and the agent
  lifecycle journal.
- Workspace release testing runs at Cargo binary-level serial granularity.
- Runtime contract tests cover the new typed child projection behavior.

## Verification

runtime host 66/66, observability 13/13, and surface interaction 36/36.
The complete workspace gate runs on the Linux release runner.
