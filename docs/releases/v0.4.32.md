# Orca v0.4.32

Hardening release: twenty-seven fixes across protocol edge cases, trust-store
concurrency, sandbox guards, ACP error reporting, provider retries, workflow
restart recovery, and terminal-bench adapter reliability.

## Changes

### Protocol and server

- Delivers the prompt byte-exact and rejects a blank prompt instead of
  silently accepting it.
- Preserves the request id when parameter deserialization fails, so error
  responses stay correlated with their request.
- Accepts the bare-string `input` shorthand alongside the structured object
  form.
- A failed request no longer terminates the JSONL server; the connection
  survives so the next request can be processed.
- Machine consumers of `--output-format jsonl` no longer see startup warnings
  on stderr (they travel in `session.started.warnings` instead).

### ACP surface

- Reports malformed client parameters as `-32602` instead of a generic
  internal error.
- Reports a client-declined permission as `refusal` rather than aborting the
  turn.

### Trust and sandbox

- Serializes trust-store writes across processes so concurrent sessions
  cannot corrupt the trust database.
- Key-folder trust uses an existence-independent check so a missing key
  does not silently grant trust.
- Guards workspace executables with the configured sandbox policy.
- Probes `bwrap` even when the workspace root is an overlay mount.
- Explains an untrusted workspace with a warning instead of failing hard.
- Reports a refused network permission grant as a structured block receipt
  instead of mislabeling it as read-only.

### Shell and process lifecycle

- Keeps the invoked name of a symlinked shell (BusyBox compatibility).
- Cancels headless runs on SIGINT/SIGTERM instead of dying immediately.
- The interrupt cancellation budget accounts for Windows' 5-second SIGTERM
  grace period.

### Provider and workflow

- Retries every 5xx response, not a fixed allow-list.
- Resolves `workflow source` against `--cwd` and the task directory.
- Restart commands resolve provider credentials from the persisted state.
- Re-runs a failed agent when its continuation is accepted.
- Resolves workflow scripts independently of the launcher's working
  directory.

### Terminal-bench adapter

- Passes the instruction after `--` so hyphen-leading prompts are not parsed
  as CLI options.
- Persists the trajectory on every exit path (including non-zero exits and
  timeouts) by teeing to an in-container copy.
- The install step survives slow image builds with a longer setup timeout.
- Exposes the `reasoning_effort` lever (`low|high|max`) for A/B benchmark
  arms under a fixed budget.
- Quarantines the unscorable `qemu-startup` task instead of silently
  reporting a zero score.
- Renames a provider tool call whose id the session already recorded,
  avoiding duplicate-id collisions.

### Documentation

- Adds a Pilion Browser integration section to the docs.

## Compatibility

No breaking changes. Existing configurations and conversation history remain
readable.
