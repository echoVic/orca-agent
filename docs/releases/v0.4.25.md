# Orca v0.4.25

Unified conversation targeting and resilient subagent relay observability.

## Changes

- Replaces the optional `focused_child_task_id` field with a single `ConversationTarget` state source, so TUI navigation, projection merges, and focus resets all read and write one typed target.
- Applies the child projection atomically when first focusing a child, so a lagging child projection can no longer overwrite the parent workflow baseline; background task updates are ignored while a child is focused.
- Aligns the registry agent identity with the surface task identity and keeps terminal surface tasks from being resurrected by a stale active registry agent.
- Classifies subagent relay lifecycle errors with bounded retry, promoting sustained failures to durable health and a `RuntimeFault` instead of silently dropping `NotFound`/`NotConnected`.
- Simplifies tool-progress classification, adds a precomputed queue preview layout, and fixes a zero-height activity render crash.
