# Orca v0.3.24

Orca v0.3.24 unifies every blocking runtime interaction behind one durable broker and removes the obsolete process-local compatibility store.

## Durable interaction recovery

- Persist Tool Approval, Permission Request, User Input, and MCP Elicitation before presenting them to a client.
- Recover restartable checkpoints after process exit, surface disconnect, and recorded-session resume without serializing Rust waiters, channels, futures, or call stacks.
- Commit a durable `InvocationStarted` receipt before tool side effects and fail closed when execution may already have started.
- Retry permission requests only from a proven pre-side-effect boundary; active or ambiguous requests remain fail closed.
- Resume accepted User Input and MCP Elicitation through a stable continuation operation identity, so a crash between answer commit and turn start converges on one durable operation.
- Keep recovered User Input and MCP content at pinned-user trust instead of promoting untrusted answers to a system message.
- Preserve the historical surface origin for continuation turns; ACP continuations require a live origin attachment and regain the standard read, write, and terminal capability handlers.

## One contract across every surface

- Route all four interaction kinds through the same broker on TUI, ACP, JSONL, and Headless.
- Add explicitly negotiated ACP extension requests for User Input and MCP Elicitation while preserving the standard permission request path.
- Give Headless an independent typed surface role with exact checkpoint projection and response submission.
- Bound Headless callback execution to one in-flight handler per transport and fail closed after timeout, preventing repeated blocked callbacks from creating unbounded OS threads.
- Reject stale revisions, route epochs, operation fences, response tokens, grant tokens, answer kinds, and execution-context fingerprints without changing the committed resolution.

## Compatibility cleanup

- Remove `RuntimePendingInteractionStore`, `RuntimePendingInteractionRecord`, the public compatibility module, and `HostedTurnRequest::with_pending_interactions`.
- Keep CLI behavior, JSONL wire shapes, model-facing tool schemas, and existing ACP standard capabilities compatible.
- Downstream Rust code that imported the removed compatibility API must migrate to the typed runtime-surface interaction contract.

## Validation

- Pass the complete four-interaction by four-surface request/response matrix.
- Cover crash recovery before presentation, after answer commit, and before continuation start.
- Verify durable fail-closed settlement for missing, executing, unsafe, unsupported, and stale-context checkpoints.
- Verify recovery permits accept exactly one operation disposition while allowing the interaction-cancellation facts that accompany safe checkpoint rejection.
- Pass runtime all-target compilation, TUI compilation, runtime-surface contract validation, exact-selector rejection, and legacy-symbol deletion gates.
