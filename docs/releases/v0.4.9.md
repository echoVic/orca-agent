# Orca v0.4.9

Live child conversations in the TUI.

This release makes delegated work a first-class part of the conversation: the
parent transcript shows each agent's activity, and a selected live child can
be opened, interacted with, and left without losing the parent session.

## Conversation activity

- Running `ChatMessage::Subagent` entries expand automatically and render the
  bounded activity history as separate indented rows.
- The current activity uses the shared spinner tick, while completed and
  attention states retain stable status markers.
- Activity labels lead with the current tool/action before turn, token, and
  elapsed metadata.
- The default activity strip uses two rows per active agent and keeps parent
  sibling activity visible while a child conversation is focused.
- Parallel starts add one grouped `Delegating to N agents` announcement.

## Live child interaction

- Selecting a live child opens its typed runtime surface rather than a stale
  checkpoint or filesystem transcript.
- Tool approvals, permission requests, user input, and MCP elicitations are
  registered against the focused child operation and routed back to that
  child.
- Direct child-to-child switching returns through the parent boundary first,
  preserving attachment fencing and FIFO projection order.
- Surface gaps reattach from a fresh snapshot and reset the child projection;
  failed or interrupted bridges detach their runtime surface cleanly.
- Parent task activity remains available to the agent dock while the child
  transcript is visible.

## Compatibility

This release changes the internal typed-surface task projection and removes
the obsolete legacy subagent event test path. Persisted task records default
the new child and batch metadata fields to `null` when loading older records.
