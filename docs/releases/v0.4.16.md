# Orca v0.4.16

Complete Goal recovery reason mapping.

## Changes

- Goal recovery maps every persisted `NotStartedReason` to the matching
  terminal semantics instead of collapsing it into RuntimeInvariant.
- Reservation expiry, admission conflicts, cancellation, restart, shutdown,
  missing capsules, and start-commit persistence failures now remain reducer
  compatible during recovery.

## Verification

- `cargo test -p orca-runtime --lib surface_goal_terminal_checkpoint_failure_recovers_exact_verified_batch --locked -- --test-threads=1`
- `cargo fmt --all -- --check`
- `cargo check -p orca-runtime --lib --offline`

## Compatibility

No persisted format or public protocol changes. Existing sessions recover with
the same durable terminal records; the live host now retains a checkpoint-failure
barrier until restart.

## Upgrade

```bash
npm install -g @blade-ai/orca@0.4.16
```
