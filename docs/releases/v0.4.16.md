# Orca v0.4.16

Complete Goal recovery reason mapping.

## Changes

- Goal recovery maps every persisted `NotStartedReason` to the matching
  terminal semantics instead of collapsing it into RuntimeInvariant.
- Reservation expiry, admission conflicts, cancellation, restart, shutdown,
  missing capsules, and start-commit persistence failures now remain reducer
  compatible during recovery.

## Verification

- Goal checkpoint recovery regression passed.
- `cargo fmt --all -- --check` passed.
- `cargo check -p orca-runtime --lib --offline` passed.

## Install

```bash
npm install -g @blade-ai/orca@0.4.16
```
