# Orca v0.4.23

Goal terminal checkpoint recovery classification patch release.

## Changes

- Detects terminal Goal batches by their durable `ContinuationDecided::Stopped` event, keeping them available for cold recovery verification.
- Continues to reconcile admitted continuation batches online.

## Verification

```bash
cargo fmt --all -- --check
cargo check --workspace --all-targets --locked
cargo test -p orca-runtime --lib surface_goal_terminal_checkpoint_failure_recovers_exact_verified_batch --locked -- --test-threads=1
cargo test -p orca-runtime --lib prepared_surface_goal_continuation_recovers_without_reexecuting_successor --locked -- --test-threads=1
```
