# Orca v0.3.23

Orca v0.3.23 introduces one runtime-owned execution layer for interactive terminal work and adds proactive background supervision for every retained terminal session.

## Unified interactive execution

- Add the model-facing `exec_command` tool for starting commands that may outlive one tool call.
- Return stable `session_id` and `task_id` values together with normalized process status, termination, exit code, output cursor, truncation metadata, and requested/effective terminal modes.
- Add `write_stdin` for sending text or raw control characters to retained sessions and for incrementally polling output.
- Support explicit PTY allocation for editors, REPLs, debuggers, and terminal UIs while keeping deterministic pipe mode as the default.
- Preserve the existing synchronous `bash` tool and JSONL shell/command protocols for compatibility.

## Terminal Supervisor

- Move terminal session state behind a bounded mailbox and a dedicated single-owner supervisor thread.
- Actively reap natural process exits and `TaskRegistry` stop requests every 25 ms, so task settlement and process-tree cleanup no longer depend on another terminal poll.
- Preserve unread output after background settlement and release per-session network proxy resources immediately at terminal completion.
- Terminate remaining process trees and join the supervisor when the runtime thread shuts down.

## Completion notifications

- Queue at most one completion notification for a command that outlives the initial `exec_command` yield.
- Inject the bounded status, exit code, and final output as pinned task context before the next model turn.
- Suppress the notification when `write_stdin` already observed the terminal result.
- Bound the queue to 64 records and each retained completion output to 8 KiB.

## Validation

- Cover natural completion without polling, external task stop settlement, exactly-once completion delivery, poll acknowledgement, concurrent session output isolation, PTY Ctrl-U behavior, stdin continuation, process-tree cleanup, and supervisor shutdown.
- Verify next-turn completion injection through the shared runtime turn entry point.
- Keep Unified Exec registry, schema, hook, event projection, history projection, and target normalization contracts covered.
- Make the closed-output streaming cancellation test independent of Bubblewrap mount permissions so it validates cancellation polling rather than host sandbox availability.
