# Orca v0.3.18

Orca v0.3.18 keeps the durable execution-budget fixes from v0.3.17 and
hardens the release workflow that publishes them.

## What Changed

- **Bounded release verification.** The Ubuntu release test job now has a
  45-minute job timeout, matching the native Windows gates. TUI library,
  TUI PTY, and workspace tests run as separate named gates, so a stalled
  command is terminated with an actionable step instead of leaving the
  release blocked indefinitely.
- **Durable execution budget.** Journal schema v2 persists immutable budget
  specs and cumulative usage facts across restart, suspension, approval
  continuation, and settlement retry.
- **Retry-safe hosted turns.** Hosted resumable cancellation is committed only
  after the host knows whether a queued resume replaces the generation.
- **Retry-safe tool accounting.** Tool admission uses an operation-local
  monotonic count, so provider retries that reuse a tool-call id are accounted
  exactly once per admission without a false duplicate-id failure.
