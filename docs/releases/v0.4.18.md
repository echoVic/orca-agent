# Orca v0.4.18

Convergent release verification.

## Changes

- Release verification now uses stable focused runtime and TUI contract gates.
- The release still performs a complete workspace compile check.

## Compatibility

No persisted format or public protocol changes.

## Verification

The release workflow runs the following gates:

```bash
cargo check --workspace --all-targets --locked
cargo test -p orca-runtime --lib --locked -- --test-threads=1
cargo test -p orca-runtime --test runtime_host --locked -- --test-threads=1
cargo test -p orca-runtime --test subagent_observability_contract --locked -- --test-threads=1
cargo test -p orca-runtime --test runtime_surface_interaction --locked -- --test-threads=1
cargo test --test subagent_contract --locked -- --test-threads=1
```
