# Orca v0.3.19

Orca v0.3.19 fixes the runtime-surface release gate so the durable budget
release can complete with bounded, observable verification.

## What Changed

- **Bounded validator execution.** Runtime-surface self-tests repeatedly
  inspect the same large TUI Rust sources while exercising synthetic inventory
  mutations. The validator now caches its lexical non-code masks by source
  content, removing the repeated full-tree scan and allowing the self-test to
  finish in a bounded time.
- **Release workflow guardrails.** The Ubuntu release test job has a
  45-minute hard timeout and reports TUI library, PTY contract, and workspace
  gates separately.
- **Durable execution budget.** The v0.3.17 journal v2, retry-safe hosted
  cancellation, and operation-local tool admission accounting remain included.
