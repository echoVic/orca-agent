# Orca v0.4.22

Goal terminal checkpoint recovery patch release.

## Changes

- Keeps a prepared Goal terminal batch durable for cold recovery while still reconciling prepared continuation batches online.
- Prevents the recovery actor from consuming the terminal batch before waiters and restart verification can observe it.

## Verification

```bash
cargo fmt --all -- --check
cargo check --workspace --all-targets --locked
cargo test -p orca-runtime --lib surface_goal_terminal_checkpoint_failure_recovers_exact_verified_batch --locked -- --test-threads=1

```
