# Orca v0.4.10

Reliable live child conversations.

This patch release hardens the v0.4.9 TUI child-conversation path after the
tagged release gate found two integration-only regressions.

## Runtime and relay fixes

- Synchronous hosted child activity commits through the actor-owned mixed
  Thread + Generation activity authority, while non-hosted CLI execution keeps
  its established event path.
- Detached workers always write a self-contained relay beginning at source
  sequence one, even when the parent surface precommits the Started fact.
- Child task parent identity may arrive before the parent task is materialized;
  the surface projection remains un-nested until the parent is available.
- Worktree-isolated synchronous children continue to use the non-hosted
  execution route.
- Typed contract tests assert task snapshots instead of the removed legacy
  `subagent.started/completed` JSONL stream.

## TUI behavior

The v0.4.9 interaction model remains unchanged: Conversation shows expanded
activity history and action-first progress, `/tasks` exposes per-agent controls,
live children can be opened and switched directly, and approvals/input are
routed to the focused child without hiding parent sibling activity.
