# Orca v0.4.15

Exact Goal recovery finalization.

## Changes

- Goal completion recovery now preserves the exact prepared terminal batch when
  a checkpoint fails, allowing cold recovery to replay the original commit.
- Recovery rebuilds completion proofs from durable tool results and maps the
  terminal record to the persisted finalization cause.
- The live host keeps the checkpoint failure barrier visible until restart,
  while the durable ledger remains authoritative for the recovered terminal.
