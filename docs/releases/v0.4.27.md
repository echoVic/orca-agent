# Orca v0.4.27

DeepSeek-native agent workflows, shared ACP sessions, actionable diagnostics,
and the canonical DeepSeek-V4.1-Flash model.

## Changes

- Adds cache-aware context management that preserves stable prompt prefixes,
  performs hierarchical remote compaction, budgets image context, and records
  durable prompt-cache checkpoints.
- Persists terminal output pages with restart-safe absolute offsets, bounded
  in-memory tails, idempotent `write_stdin.output_offset` polling, and
  Windows-compatible archive path validation.
- Adds file-defined custom Agents from user and trusted-project
  `.orca/agents/*.md` files. Definitions are validated, permission-narrowed,
  frozen for execution, and preserved across synchronous and asynchronous
  continuation.
- Adds the Unix ACP daemon, TUI/headless/editor attachment, single-writer
  coordination, reconnect, durable history recovery, and race-free graceful
  signal handling once its socket becomes reachable.
- Preserves typed sandbox probe evidence and keeps restricted execution
  fail-closed. When OS sandbox enforcement is unavailable, Orca removes new
  shell-launch tools while retaining file tools and existing terminal control,
  then surfaces one actionable `/doctor` warning. The diagnostics path is
  conditionally compiled for native Windows AppContainer checks.
- Adds structured TUI diagnostics with stable codes, bounded causes, recovery
  guidance, typed terminal mapping, ACP transport, and restart-safe display.
- Makes `deepseek-flash` the canonical Flash model. The retired
  `deepseek-v4-flash` and `deepseek-v4-flash-vision-exp` names remain accepted
  inputs, normalize before routing and persistence, and use Flash pricing.
  DeepSeek-V4.1-Flash receives image blocks directly; `auto` and Pro use Flash
  for task-aware image analysis.

## Compatibility

Existing configuration, Agent definitions, ACP requests, saved settings, and
CLI invocations that use `deepseek-v4-flash` or
`deepseek-v4-flash-vision-exp` remain valid. Orca records and displays the
canonical `deepseek-flash` name after loading them.

Restricted shell execution still requires a working OS sandbox backend.
`/trust` does not change that enforcement boundary. Hosts that prohibit nested
Seatbelt or bubblewrap profiles now receive explicit probe evidence instead of
an unsafe fallback.
