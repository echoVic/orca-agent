# Orca v0.4.21

Independent child-thread agent runtime and canonical Agent Dock updates.

## Changes

- Registry-backed child agents are visible in Conversation and can be focused with the existing Dock controls.
- Child launch announcements are emitted once per delegation batch.
- Child execution profiles are inherited explicitly and process launches no longer claim remote execution without a backend.
- Agent event attempts use unique fences and failed journal appends do not consume source sequence numbers.
- Child operation output is retained as canonical `OutputDelta` events instead of being sent to `io::sink()`.

## Compatibility

This release removes the old root-transcript child snapshot presentation path. Child conversation state is owned by the child thread and Agent Dock projections.
