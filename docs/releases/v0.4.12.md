# Orca v0.4.12

Deterministic child activity release.

This patch ships the live child conversation fixes and makes the release
workspace gate deterministic for tests that use process-level runtime state.

## Changes

- Keep child activity expanded and interactive in Conversation.
- Preserve parent sibling activity while a child is focused.
- Route synchronous and detached child activity through the correct surface
  authority and keep detached relay sequence one self-contained.
- Retain the non-hosted CLI and worktree-isolated subagent paths.
- Run the complete workspace gate with Cargo's binary-level sequential test
  execution and one test thread per binary.

## Verification

Local child/runtime/TUI gates passed before publication. The release workflow
uses `cargo test --workspace --all-targets --no-fail-fast -- --test-threads=1`
so process-level `ORCA_HOME` fixtures cannot overlap across binaries.

## Install

```bash
npm install -g @blade-ai/orca@0.4.12
```
