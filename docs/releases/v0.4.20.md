# Orca v0.4.20

Four-plane agent runtime foundations.

## Changes

- Root conversations retain only one delegation announcement; child activity and output stay in the child thread and dock projection.
- Agent controller launches record identity-bound events in the canonical agent registry journal.
- Terminal registry agents reject late activity instead of reopening as running.
- Release verification restores the locked workspace clippy and nextest gates.

## Compatibility

This release intentionally removes the old root-transcript `ChatMessage::Subagent` presentation path. Derived state is rebuilt from current runtime projections; source transcripts are preserved.

## Verification

```bash
cargo fmt --all -- --check
cargo clippy --workspace --all-targets --locked -j 1
cargo nextest run --workspace --all-targets --locked --profile ci --no-fail-fast
cargo test -p orca-runtime --lib --locked -- agent_registry -- --test-threads=1
cargo test -p orca-tui --lib --locked -- task_snapshot_keeps_running_subagent_out_of_main_conversation -- --test-threads=1
```

## Upgrade

```bash
npm install -g @blade-ai/orca@0.4.20
```
