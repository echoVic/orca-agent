# Orca v0.4.11

Stable serialized release gate.

This patch republishes the v0.4.10 live child conversation fixes and makes
the release workspace gate deterministic by running its shared-state tests
with one test thread.

## Changes

- Keep Conversation child activity expanded, action-first, and interactive.
- Preserve parent sibling activity while a child is focused.
- Keep detached relay sequence one self-contained after precommitted starts.
- Retain the non-hosted CLI subagent path and worktree isolation behavior.
- Run the full release workspace nextest gate with `--test-threads 1`.

## Verification

The v0.4.10 local gates passed: TUI library 1271 tests, PTY 9 tests,
subagent contract 13 tests, observability 13 tests, and surface commit 39
tests. v0.4.11 additionally validates the serialized workspace release gate.

```bash
npm install -g @blade-ai/orca@0.4.11
```
