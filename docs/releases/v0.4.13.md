# Orca v0.4.13

Fenced async child routing.

This patch finalizes the live child conversation release after the v0.4.12
PTY gate exposed one remaining async routing ambiguity.

## Changes

- Route async subagents with a typed parent operation fence through durable
  task ownership so `/tasks` always exposes the running child.
- Route legacy hosted async agents without a parent fence through the live
  agent controller and return their child thread identity directly.
- Preserve one parentless root session while allowing persisted live child
  sessions.
- Keep the agent lifecycle journal separate from session-ledger assertions.
- Retain the non-hosted sync fallback and worktree-isolated child path.
- Run the Linux workspace release gate at binary-level serial granularity.

## Verification

cargo test -p orca-tui --lib --locked -- --test-threads=1
cargo test --test tui_pty_contract --locked -- --test-threads=1
cargo test --test subagent_contract --locked -- --test-threads=1
cargo test -p orca-runtime --test runtime_host --locked -- --test-threads=1
cargo test -p orca-runtime --test subagent_observability_contract --locked -- --test-threads=1
cargo test -p orca-runtime --test runtime_surface_interaction --locked -- --test-threads=1

The complete Linux workspace gate runs in the release workflow. Local macOS
server command-exec tests that require a Linux enforcement backend are not
used as evidence on this host.
