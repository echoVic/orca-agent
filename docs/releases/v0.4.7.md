# Orca v0.4.7

Subagent observability and permission-recovery architecture release.

## Observable child agents

- Route synchronous and asynchronous child activity through one typed surface
  ingress and durable event relay.
- Drain relay events while the host is active or idle, with bounded replay,
  deduplication, corruption quarantine, and reconnect-safe cursors.
- Render child tasks as an expandable tree in the TUI and expose the child
  transcript through the same task identity.
- Keep session search and completion proof tied to durable surface state.

## Permission and authority boundaries

- Bind detached permission requests to deterministic task/agent/activity
  identities and idempotent mailbox records.
- Authenticate detached Allow responses with an actor-only Ed25519 signer;
  restart without the signer fails closed.
- Make cancellation and timeout terminal Deny decisions durable and
  linearizable against a racing actor response.
- Retain Allow tombstones until child acknowledgement and compact only safe
  terminal Deny records.
- Reject generic ActorControl task identity/ownership rewrites, detached
  prepared starts without an admission proof, historical generation revival,
  and Task/Subagent status mismatches.
- Re-check permission response profiles against the persisted request at the
  commit authority boundary.
- Classify terminal detached interactions as Thread-owned cleanup even after
  task state has cleared its pending marker.

## Breaking changes

This release intentionally tightens the surface authority contract. Prepared
detached `Started` batches without a durable admission proof, generic task
identity rewrites, and permission profiles broader than the request are now
rejected. Detached permission schema and mailbox records use the current
authenticated format; older malformed or unsigned records fail closed.
