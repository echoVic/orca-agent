This Rust crate implements a small order-pricing pipeline split across ten modules. Several steps are
unfinished (`todo!()`), and the money rounding is probably wrong.

Make the crate's test suite pass (`cargo test`). Do not modify the tests.

The workspace also contains the project's architecture notes under `docs/`. Read them before you change
behaviour: they record conventions the pipeline already follows, and some of them are not visible in
the code.
